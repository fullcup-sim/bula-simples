# PRD — Bula Simples

**Criador:** Tiago Nunes (@tiago.nunes)
**Categoria:** saude

## Problema

Bula de remédio reescrita em linguagem simples, com dose, horário e alerta de interação lidos em voz alta para quem tem pouca leitura.

## Marcos

1. Leitura de bula por foto
2. Resumo em linguagem simples
3. Alerta de interação entre remédios
4. Leitura em voz alta

## Fora de escopo (v1)

Qualquer coisa além do marco declarado acima. Escopo cresce por marco novo, não por ajuste no atual.
